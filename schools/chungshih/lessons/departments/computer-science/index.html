資訊科 Computer Science Department — 科系介紹影片

The Computer Science department equips students with skills in programming, networking, and cybersecurity. Our practical curriculum prepares graduates for immediate employment. Empower your future with advanced IT knowledge and hands-on experience.

What You Study · 主要學習內容
To give students practical technical skills in computer systems and programming.
  • Computer System Installation and Configuration電腦系統安裝與設定
  • Software Programming軟體程式撰寫
  • Network System (Server) Installation and Configuration網路系統（伺服器）安裝與設定
  • Microcontroller Programming, Circuit Assembly and Testing單晶片微電腦控制程式編寫及電路裝配與測試

目標：提供學生與電腦系統及程式設計相關的實務技術技能。

Words to Learn · 單字學習

Tap 🔊 to listen · 點喇叭聽發音

programming/ˈproʊ.ɡræm.ɪŋ/程式設計

Programming turns an idea into working software.程式設計把想法變成能運作的軟體。

network/ˈnet.wɝːk/網路

We set up a network so the computers can talk to each other.我們架設網路，讓電腦彼此溝通。

server/ˈsɝː.vɚ/伺服器

The server stores the files for the whole school.伺服器為全校儲存檔案。

cybersecurity/ˌsaɪ.bɚ.sɪˈkjʊr.ə.t̬i/資訊安全

Cybersecurity protects data from attacks.資訊安全保護資料不受攻擊。

hardware/ˈhɑːrd.wer/硬體

Hardware repair starts with finding the faulty part.硬體修護的第一步是找出故障的零件。

microcontroller/ˌmaɪ.kroʊ.kənˈtroʊ.lɚ/單晶片微電腦

A microcontroller runs the program inside a small device.單晶片微電腦在小裝置裡執行程式。

web design/web dɪˈzaɪn/網頁設計

Web design makes information easy to read online.網頁設計讓資訊在網路上容易閱讀。

install/ɪnˈstɑːl/安裝

First install the operating system, then the drivers.先安裝作業系統，再安裝驅動程式。
