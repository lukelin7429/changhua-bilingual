Lion Dance English

舞獅英語 · 六堂課 · 把饒明的特色變成孩子能說的英文
The lion dance is a proud Raoming tradition — so we turned it into a 6-lesson English course. Every lesson has vocabulary with audio, easy sentence patterns, a two-person dialog you can listen to, and a fun class game.
舞獅是饒明引以為傲的特色，我們把它做成了一套 6 課的英語課程。每一課都有單字（含 🔊 發音）、簡單句型、可以聽發音的兩人對話練習，還有課堂遊戲。
