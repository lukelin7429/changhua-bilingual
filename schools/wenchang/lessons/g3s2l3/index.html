Sentence Patterns 句型

Key Patterns
Pattern 1 · 詢問動物
Is it a ___?
A:Is it a bear?
B:Yes, it is.
A:Is it a tiger?
B:No, it isn't. It's a lion.
A:Is it a monkey?
B:Yes, it is. It's a monkey.
Pattern 2 · 肯定與否定回答
Yes, it is. / No, it isn't. It's a ___.
Yes, it is.
No, it isn't.
No, it isn't. It's a horse.

Grammar Focus 文法重點

isn't = is not
isn't = is not

To make a Yes/No question with "it is", move "is" to the front.

Statement: It is a tiger.  →  Question: Is it a tiger?

Short answers:

Yes, it is.  (NOT "Yes, it's.")
No, it isn't.  (isn't = is not)

Question 問句 Yes answer 肯定回答 No answer 否定回答
Is it a bear? Yes, it is. No, it isn't. It's a tiger.
Is it a horse? Yes, it is. No, it isn't. It's a goat.
