Sentence Patterns 句型

Key Patterns
Pattern 1 · 詢問近處物品
What's this? — It's a/an ___
A:What's this?
B:It's a pen.
A:What's this?
B:It's an eraser.
Pattern 2 · 詢問遠處物品
What's that? — It's a/an ___
A:What's that?
B:It's a ruler.
A:What's that?
B:It's a marker.

Grammar Focus 文法重點

a vs. an
a vs. an — When to Use Each

Use a before words that start with a consonant sound.

Use an before words that start with a vowel sound (a, e, i, o, u).

Article 冠詞 Word 單字 First Sound 第一個音 Example 例句
apen/p/ consonant 子音It's a pen.
apencil/p/ consonant 子音It's a pencil.
aruler/r/ consonant 子音It's a ruler.
amarker/m/ consonant 子音It's a marker.
aneraser/ɛ/ vowel 母音It's an eraser.
anapple/æ/ vowel 母音It's an apple.
this vs. that 這個 vs. 那個

this = something close to you. 指靠近你的東西。

that = something far from you. 指離你較遠的東西。

Mini Quiz · 小考

Select the best answer for each question. 選出每題最適合的答案。

Question 1 / 10
A: What's this?  B: It's eraser.
Correct. "eraser" starts with a vowel sound /ɛ/ → use an.
"eraser" starts with a vowel sound /ɛ/ → use an eraser.
Question 2 / 10
Which word uses "an" before it? 哪個單字前面要用 "an"？
Correct. "eraser" starts with a vowel → an eraser. The others start with consonants (p, r, m).
"eraser" starts with the vowel sound /ɛ/ → an eraser. pen, ruler, and marker all start with consonant sounds.
Question 3 / 10
You are pointing to something right next to you. Which question do you ask? 你指著就在你旁邊的東西，你問哪一句？
Correct. Use What's this? for something close to you.
Use What's this? for something close. "What's that?" is for something far away.
Question 4 / 10
A: What's that?  B:
Correct. It's a pencil. — we answer with "It's" and remember to use the article "a".
The correct answer is (C) It's a pencil. — answer with "It's" + article "a/an" + noun.
Question 5 / 10
It's pen.
Correct. "pen" starts with the consonant /p/ → use a pen.
"pen" starts with the consonant /p/ → use a pen, not "an".
Question 6 / 10
Which sentence is correct? 哪個句子正確？
Correct. "marker" starts with /m/ (consonant) → It's a marker. The others all have the wrong article.
(D) is correct. "marker" → /m/ consonant → a. "eraser/apple" need "an"; "ruler" needs "a".
Question 7 / 10
The book is far away from you. Which question do you ask? 那本書離你很遠，你問哪一句？
Correct. Use What's that? for something far away from you.
Use What's that? for far objects. "What's this?" is for objects close to you.
Question 8 / 10
What does "ruler" mean in Chinese? "ruler" 的中文是什麼？
Correct. ruler = 尺. eraser = 橡皮擦, marker = 麥克筆, pencil = 鉛筆.
ruler = 尺. Remember: eraser = 橡皮擦, marker = 麥克筆, pencil = 鉛筆.
Question 9 / 10
A: What's this?  B:
Correct. It's a pencil. — always use "It's" to answer What's this/that? questions.
The correct answer is (B) It's a pencil. — "It's" + article + noun. Never start with "That's" when answering What's this?
Question 10 / 10
What does "eraser" mean in Chinese? "eraser" 的中文是什麼？
Correct. eraser = 橡皮擦. And remember: eraser starts with a vowel, so it's an eraser!
eraser = 橡皮擦. pen = 原子筆, marker = 麥克筆, ruler = 尺.
