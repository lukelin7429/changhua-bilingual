Coding for Smart Kids游於智 — 程式學習課程

Our students are having fun in the "Coding for Smart Kids" program! In this class, children learn the basics of coding through hands-on practice and exploring.

The students are learning to think like programmers. They find problems, try to fix them, and slowly understand how to use logic and creativity. Every time they code and change something, they are growing smarter! Learning to code is not just about gaining skills; it's a journey where every child feels free to explore and proud of what they create.

在「游於智程式課程」中，學生們透過實際操作與探索，不僅學習程式編成的基礎知識，更逐步培養程式編輯的能力。

孩子們在練習中發現問題、嘗試解決，慢慢掌握邏輯思維與創意思考的方法。每一次的操作與修改，都是他們自我成長的腳步，讓程式學習不只是技能的累積，更是一段自在而充滿成就感的探索旅程。

Words to Learn · 單字學習

coding/ˈkoʊdɪŋ/程式設計

Coding is like giving the computer directions.寫程式就像給電腦指路。

computer/kəmˈpjuːtər/電腦

We tell the computer exactly what to do.我們告訴電腦該做什麼。

program/ˈproʊɡræm/程式

A program is a list of clear steps.程式就是一連串清楚的步驟。

logic/ˈlɑːdʒɪk/邏輯

Coding teaches us to use logic.寫程式教我們運用邏輯。

problem/ˈprɑːbləm/問題

First we find the problem.我們先找出問題。

fix/fɪks/修正、解決

Then we try to fix it, step by step.然後一步一步試著把它修好。

practice/ˈpræktɪs/練習

We learn through hands-on practice.我們透過動手練習來學習。

explore/ɪkˈsplɔːr/探索

Every child is free to explore.每個孩子都能自由探索。
