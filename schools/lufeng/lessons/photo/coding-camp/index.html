Going Further進階閱讀

During the winter break, Lufeng students join a coding camp in the computer room. They learn to type commands, write simple programs, and watch their code run on the screen. Step by step, they turn ideas into projects. Coding teaches them to think clearly and never give up when something does not work.

寒假期間，陸豐的學生在電腦教室參加玩程式營。他們學會輸入指令、寫簡單的程式，看著自己的程式碼在螢幕上跑起來。一步一步，把想法變成作品。寫程式教他們清楚地思考，也教他們遇到問題時不放棄。
